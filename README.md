Project

This project is about working with and analyzing data using Python.

The project includes the dataset, Python scripts, a Jupyter Notebook, reports, meeting notes, and images related to the analysis.

Project Files
data contains the dataset.
src contains the Python scripts.
reports contains the Jupyter Notebook.
images contains images and plots.
docs contains reports and meeting notes.
environment.yaml contains the information needed to recreate the project environment.

The main tools used in this project are Python, pandas, matplotlib, and scikit-learn.
